# Catch Redbook Opinion Monitor

小红书舆情监管本机/云端轻量应用。

## 功能

- 默认品牌词可在页面修改。
- 支持小红书舆情日报、本地 JSON 存储、全量相关内容分析。
- 默认每次目标抓取 50 条。
- 首次巡检默认回溯最近 7 天，后续每日巡检关注新增内容。
- 页面提供今天、昨天、最近七天、最近一个月快捷筛选。
- 抓取时显示进度条，完成后提示关闭。

## 本地运行

```bash
python3 server.py
```

然后打开：

```text
http://127.0.0.1:8765/小红书舆情监管.html
```

## 云端运行

本仓库已包含 `render.yaml`、`Procfile` 和 `requirements.txt`。在 Render 创建 Web Service 时可使用：

```bash
HOST=0.0.0.0 python3 server.py
```

## 重要说明

小红书真实采集依赖已登录页面能加载出的可见卡片。若页面只导入 19 条，表示当前浏览器页面实际只加载了 19 条，需要继续向下滚动搜索结果页加载更多内容后再导入。
